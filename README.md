# ハーベスト・ローグ

空腹度を行動力にして畑を広げ、納期ノルマに挑む **農業ローグライク・インクリメンタル・自動化コロニーシム** のブラウザ版プロトタイプです。
仕様書「農業ローグライク自動化コロニーシム 仕様書（ドラフト）」をもとに作っています。

ビルド不要の HTML / JavaScript（ES Modules）だけで動きます。

## 遊び方

- 耕す・植える・収穫する・運ぶ・納品する。すべての手作業で **空腹度（＝行動力）** が減ります
- 収穫した作物は **食べる**（空腹度回復）／**納品する**（ノルマ・コイン）／**燃やす**（電力）の取り合い
- 「〇日以内に〇〇を〇個納品」のノルマを期限までに達成すると、3つの候補からアップグレードを1つ選べます。未達ならラン終了
- 途切れずに納品し続けると **コンボ倍率** が上がり、ブレイクビーツのパートが重なっていきます。コンボが切れると音が抜けます
- ノルマ期間中は **雹や嵐** が発生します。**天候防御パイロン** で範囲内の作物を守れます
- ラン終了時に持ち帰る **種籾** で、次のランを楽にする永続強化を買えます

### 操作

|            | 1P    | 2P       |
|------------|-------|----------|
| 移動       | WASD  | 矢印キー |
| アクション | Space | Enter    |
| 食べる     | Q     | 右Shift  |

- 1〜6: 植える作物を選ぶ
- マウス: ツールバーで建物を選んでクリックで建設（R で向きを回転、右クリックで解除）
- X: 撤去ツール / T: 農場管理端末（コンソール） / H: ヘルプ / P: 一時停止
- 1人プレイのときは矢印キー・Enter でも操作できます

### バランス調整

- まな板を手で使えるのは1日4回まで（何度でも複製できた問題の修正）
- ノルマの伸びを 1.55倍 → 1.5倍に。必要数は収穫数（トマト・トウモロコシは2）も考慮し、協力プレイは人数に応じて増える
- 次のノルマの作物とボスを前もって表示
- 悪天候は3つ目のノルマから。嵐の強さはノルマが進むにつれて上がる（毎秒2% → 6%）
- 夜（1日の終わり）に空腹度が8減る
- バイオマス発電機の燃料1あたりの電力を 12 → 20 に
- 倍率スロットは掛け算ではなく足し算で重なる
- 永続強化に「形見のお守り」「大きな巾着（お守りの枠 +1）」を追加

未実装・簡略化したもの: ルート移動回収装置、干ばつや害虫、ボクセル／低解像度3Dの表現。

## オンライン協力プレイ（Cloudflare）

タイトル画面の「部屋を作る」でホストになり、表示された4文字の部屋コードを友だちが「参加する」に入力すると、最大4人で同じ農場を遊べます。途中参加・途中退出もできます。

- 方式: ホストのブラウザがゲームを計算し、0.1秒ごとに状態を配信します。ほかの人は操作をホストへ送ります（ホスト権威型）。サーバー側はメッセージを中継するだけです
- サーバー: `worker/` の Cloudflare Worker。部屋ごとに Durable Object が WebSocket を中継し、ゲーム本体の静的ファイルも同じ Worker から配信します
- ホストが抜けると、その部屋のランは終了します
- アップグレードの選択と市場での買い物は誰が操作しても反映されます。端末のコマンド（`gambit` など）もホスト上で実行されます（`giveup` はホストのみ）

### デプロイ

`main` に push すると GitHub Actions（`.github/workflows/deploy-worker.yml`）が Cloudflare にデプロイします。事前にリポジトリの Settings → Secrets and variables → Actions に次の2つを登録してください。

| 名前 | 値 |
|---|---|
| `CLOUDFLARE_API_TOKEN` | Cloudflare のダッシュボードで「Edit Cloudflare Workers」テンプレートから作った API トークン |
| `CLOUDFLARE_ACCOUNT_ID` | Cloudflare のアカウント ID（Workers & Pages の画面右側に表示） |

未登録のあいだはデプロイの手順がスキップされます。デプロイ後は `https://harvest-rogue.<アカウントのサブドメイン>.workers.dev/` でオンライン対応版を遊べます。GitHub Pages 版からもオンラインに接続したい場合は、その URL を `src/config.js` の `MP_SERVER` に書いてください。

手元で試すときは:

```sh
cd worker
npm install
npm run dev   # http://localhost:8787/
```

Durable Objects は Cloudflare の無料プランでも使えます（SQLite 版）。1部屋あたりホストが毎秒10回状態を送るので、無料枠（1日あたりのリクエスト数）の範囲で遊ぶ想定です。

## ローカルで動かす

ES Modules を使うため、ファイルを直接開くのではなくローカルサーバー経由で開いてください。

```sh
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

`?assets=off` を付けると外部画像を読み込まず、代替のドット絵だけで表示します。

## GitHub Pages で公開する

リポジトリの Settings → Pages で、Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にすると公開されます。

## 素材

ドット絵素材は [DOT ILLUST](https://dot-illust.net/)（管理人 nko 様）のものを使用しています。

- 利用規約: https://dot-illust.net/terms/
- 商用・非商用とも無料、クレジット表記は不要とされていますが、感謝を込めてここに記載しています
- 規約で **素材の再配布が禁止** されているため、このリポジトリには素材ファイルを含めていません。ゲーム実行時にブラウザが DOT ILLUST から直接読み込みます（`src/data.js` の `DOT_ILLUST` に一覧があります）
- 読み込めない場合は、`src/sprites.js` の代替ドット絵で表示します
- 商用利用の場合は「1つの制作物につき30点まで」の制限があります（**現在の使用数は30点で上限に達しています**。これ以上追加するときは、どれかを外してください）

使用している素材: 草原・土・畑（ニンジン/大根/白かぶ）のマップタイル、ニンジン、大根、トマト、とうもろこし、かぼちゃ、村人（ヤング/男性・女性・青・オレンジ）、宝箱（ブロンズ/シルバー/ゴールド）、レンガ、天気アイコン（晴れ/大雪/雷雨）、石（氷）、乾電池、カラス、神さま（ゴールド・神託の祝福）、モンスター（死神・神託の呪い）、木箱（補給物資）、勾玉（お守り）、毒（腐った作物）、ロボット掃除機（自動収穫機）。

かかし・ドローン・発電機などの機械は、DOT ILLUST に合う素材がないか、30点の上限に収まらないため、コードで描いています。

### 効果音

効果音は [Kenney](https://kenney.nl/) の CC0（パブリックドメイン）素材を MP3 に変換して `assets/sfx/` に同梱しています。元素材の対応は [assets/sfx/CREDITS.md](assets/sfx/CREDITS.md) にあります。ファイルを読み込めない環境では WebAudio の合成音で鳴らします。

コンボで重なっていくブレイクビーツ（BGM）だけは、今も WebAudio で合成しています。取得できる CC0 のドラムループが見つからなかったためです。
