# 物理演算

地面に落ちている作物に、重さ・高さ・弾み・ぶつかり合いを持たせています。既定でオンです。

## 切り替え方

- 農場管理端末（T）で `physics on` / `physics off`。設定はブラウザに保存され、次のランにも引き継がれます
- URL に `?physics=1` を付けて開くとオン、`?physics=0` でオフ
- 実験機能だったころ（既定オフ）の保存は引き継ぎません。全員オンから始まります

## オンのときの動き

| 場面 | オフ（以前の動き） | オン |
|---|---|---|
| 収穫・撤去・補給物資のあふれ | その場に散らばる | ぽんと跳ね上がって着地し、少し弾む |
| 作物どうし | 同じ場所に重なる | ぶつかって押し合い、壁際に山になる |
| 壁・建物に当たる | その場で止まる | 跳ね返る |
| プレイヤーが歩く | すり抜ける | 足元の作物を蹴って押しのける |
| 扇風機の風 | どの作物も同じ速さで、風の軸に吸い寄せられて流れる | 風速と作物の速度の差に空気抵抗がかかる（下の表） |
| 嵐の風 | どの作物も同じだけ流される | 扇風機と同じ空気抵抗で、軽い作物ほど流される |
| 雹 | 畑の作物だけ傷む | 地面に当たった雹が近くの作物を弾き飛ばす |

ベルトコンベアとパイプの上ではベルトが運び、作物どうしは間隔をあけて並びます。

### 扇風機

- 風速は扇風機のすぐ前が最も強く（260 px/秒）、届く範囲（5マス、建物で遮られるまで）の端では 45% まで弱まります
- 作物は「風速 − 自分の速度」に比例する力を受け、それを質量で割った分だけ加速します。地面の摩擦とつり合ったところが流れる速さです
  - 扇風機の前: ニンジン 約150 / カボチャ 約85 px/秒、範囲の端: ニンジン 約70 / カボチャ 約40 px/秒
- 風に沿わない向きの速度も空気抵抗で消えるので、作物は風の通り道に沿ってまっすぐ流れます（以前のように軸へ吸い寄せる力はありません）
- 手前（扇風機側）に作物があると、その陰に入った作物に届く風は 55% に弱まります（何個重なっても最低 25%）。前の作物にぶつかって押されるので、列ごと流れます
- 強い風を受けた軽い作物は、転がって小さく跳ねます

重さ: カボチャ 3 / ダイコン 1.6 / トウモロコシ 1.2 / ニンジン 1 / カブ 0.9 / トマト・腐った作物 0.8

## 実装

- 数値と処理は `src/physics.js` にまとめています（`PHYS` の値を変えると調整できます。風は `applyWind()` と `fanWindAt()`）
- `src/game.js` は `this.physics` がオンのときだけ `physics.js` の関数を呼びます。扇風機は `fanPush()` → `fanWind()`
- オンライン協力（PR #1）と合わせる場合、ゲストに跳ねる高さを見せるには `serialize()` / `applySnapshot()` のアイテムに `z` を足します。足さなくてもゲーム進行は同じで、ゲスト側では跳ねずに表示されるだけです
