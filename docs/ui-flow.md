# 画面とプレイの流れ

## 1ランの流れ

```
タイトル
  ① 特性を1つ選ぶ
  ② 縛りを付ける（任意）
  ③ 始める（Enter でも1人で開始）
    ↓
ノルマ（3日 × 1日40秒）  ←──────────────┐
  毎朝: 神託（ラン最初の日は無し）・旬の作物・カラスの予告   │
  3つ目ごとのノルマはボス（前のノルマのうちに予告）   │
  期限切れ → 1日延長（延滞料: コインの2割）をくり返す │
    ↓ 納品してノルマ達成                          │
ノルマ達成 → アップグレード（1つ選ぶ） → 市場（お守り） ┘

いつでも: プレステージ（ツールのボタン / 端末の prestige）
手詰まりを検知: 右上に「プレステージしませんか？」
    ↓ プレステージする
プレステージ（区切った理由と成績）→ タイトルへ（種籾で永続強化）
```

ノルマの期限を過ぎてもランは終わりません。期限が1日ずつ延び、延びるたびに延滞料としてコインの2割を払います。

### 手詰まりの検知とプレステージの提案

1秒ごとに次のどれかに当てはまるかを調べ、当てはまったら畑の右上に「プレステージしませんか？」を出します（ゲームは止めません）。

| 種類 | 条件 |
|---|---|
| 空腹で何もできない | 全員の空腹度が耕す・植えるのに足りず、手持ち・地面・畑・建物・ドローンのどこにも作物が無い（お守り「牧場主」を持っていれば毎朝回復するので除く） |
| 延長が続く | 期限の延長が2回目に入った |
| 間に合わない見込み | 延長中で、直近1日の納品ペース × 延長の残り時間 ＋ 手元・地面・畑にあるノルマの作物（期限までに熟すもの）では、ノルマに届かない |

「まだ続ける」を選ぶと1日は出しません。新しく延長になったときや、ツールの「プレステージ」ボタンを押したときはまた出ます。当てはまらなくなったら提案は自動で消えます。

アップグレードと市場の画面には、いまどの段階にいるかを示す「ノルマ達成 ▸ アップグレード ▸ 市場 ▸ 次のノルマ」の表示があります。どちらの画面にも次のノルマ（作物・個数・ボス）を同じ形で出します。

## プレイ中の画面

| 場所 | 中身 |
|---|---|
| 上段 | ノルマ（番号・ボス名・進み具合）、期限、コイン、電力、コンボ、天気 |
| 情報欄（1行） | 神託、旬、次のノルマ、お守り。長い説明はマウスを乗せると出る |
| 畑の上（中央上） | 次にやることの案内。最初のノルマのあいだだけ「耕す → 植える → 収穫・拾う → 納品」を順に出す。空腹度が25%を切ったらいつでも「Q で食べる」を出す |
| 畑の左下 | お知らせ。ゲームのメッセージ（新しいノルマ、神託、カラス、天気、ボス突破など）を最新3件、8秒間出す |
| 下段 | プレイヤー（空腹度・手持ち）、植える作物、建設、ツール |

## キー操作の早見表

| 画面 | キー |
|---|---|
| タイトル | Enter: 1人で開始 |
| プレイ中 | 移動 WASD / アクション Space / 食べる Q / 1〜6・ホイール 作物 / X 撤去 / T 端末 / H ヘルプ / P 一時停止 / Esc ツールとクリックの指示を取り消し |
| アップグレード | 1〜3: 選ぶ |
| 市場 | 1〜3: 買う / R: 品替え / Enter: 次のノルマへ |
| プレステージ | Enter: タイトルへ |

## マウス操作

| 場面 | 操作 |
|---|---|
| 建設ツールなし | マスをクリック: 歩いて行ってアクション（空き地は耕して植える）/ ドラッグ: 通ったマスを順番に指示 / Shift+クリック: 指示を足す / 右クリック: 指示を取り消し |
| マウスを乗せる | そのマスで何をするか（耕して植える・収穫・拾う ×n・納品する など）を表示。できないことは赤 |
| 建設ツールあり | クリックで建設 / ドラッグで続けて建設（ベルト・パイプはドラッグの向きに向き、直前のベルトも曲がる）/ 右クリックで解除 |
| プレイヤー欄 | 「食べる」ボタン |
| ツール | 「プレステージ」ボタン |

キー操作で動くと、クリックの指示は取り消されます。マウス操作は 1P だけです。

## 実装の場所

- 案内とお知らせ: `src/guide.js`（`main.js` の `updateHud()` から毎フレーム呼ぶ）
- 画面の切り替え: `src/main.js`（`frame()` が `game.state` の変化を見てアップグレード・プレステージを出す。市場は `chooseUpgrade()` のあとに出す）
- クリック操作: `src/game.js` の `orderAt()`（指示を積む）・`followOrders()`（道を探して歩き、着いたら `actAt()`）・`describeAction()`（マウスを乗せたときの表示）
- 期限切れと手詰まり: `src/game.js` の `extendQuota()`・`updateStall()`・`stallReason()`・`prestige()`。提案の表示は `main.js` の `updatePrestigeOffer()`
- ゲームの状態: `src/game.js` の `state`（`playing` → `upgrade` → `shop` → `playing`、または `over`）
